# Documentation links resolve — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a test that fails on any relative markdown link or anchor in `README.md` or `docs/**/*.md` that does not resolve, seen red on the two broken links first, then the links fixed.

**Architecture:** One task, one red→green loop with four controls. `DocumentationLinksTest` in `com.robsartin.segue.arch` on `RepositoryTree`: walk the files, strip fenced blocks and inline code spans, extract links, resolve paths and anchors (GitHub slug rule, duplicate suffixes), report every failure at once with file:line. No production change, no ADR.

**Tech Stack:** Java (toolchain 25, `release 21`), JUnit, AssertJ.

**Spec:** `docs/superpowers/specs/2026-09-02-doc-links-design.md`

## Global Constraints

- **Pure TDD**: the test first, RED on the unchanged tree naming exactly the two `0042` links (quote it); then the controls; the two links fixed last → GREEN.
- Test names `should<Expected>When<Condition>` with `@DisplayName`. **No ADR.** **Never `git add -A`**; stage by explicit path with git's stderr visible.
- Gate, **blocking**: `SEGUE_REQUIRE_BROWSER=true ./gradlew check --rerun-tasks`. Baseline on `main` is 1058 tests — measure it.
- **Only JDK 25 is installed; Gradle 9.7.1 launches on it.** Plain `./gradlew`; never `java_home -v 21`.
- **Never run a writing dev task**; `~/.segue/segue.db` is never read, written, or created.
- **Slug rule is GitHub's, exactly**: lowercase; remove every character that is not a Unicode letter, digit, space, hyphen or underscore; spaces → hyphens; **no hyphen collapsing**; the second identical heading in a file gets `-1`, the third `-2`. State it in the test's javadoc.
- **Skip** links inside fenced code blocks (```` ``` ```` … ```` ``` ````) and inline code spans (odd number of backticks before the link on its line); skip `http:`, `https:`, `mailto:` targets. Everything else is checked — including `docs/superpowers/**`.
- Never cite a `.superpowers/` path from a committed file.
